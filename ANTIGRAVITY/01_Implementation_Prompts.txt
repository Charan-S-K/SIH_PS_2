SECUREMAILSCOPE — ANTIGRAVITY IMPLEMENTATION PROMPTS

GLOBAL ANTIGRAVITY RULES
==========================
- Read the existing repository before changing anything.
- Create the current stage branch BEFORE implementation:
  feature/stage-XX-short-name
- If there are uncommitted user changes, do not overwrite them; stop and report.
- Implement ONLY the requested stage.
- Do not silently implement future stages.
- Preserve working previous-stage behavior.
- Add tests for normal, edge, invalid, and insufficient-evidence cases.
- Treat PCAPs as untrusted input.
- Never invent packet/TLS/certificate/crypto facts; use UNKNOWN when evidence is unavailable.
- Use free/open-source and locally deployable components.
- Never hard-code secrets or credentials.
- Review git diff/status before stopping.
- DO NOT git commit.
- DO NOT git push.
- DO NOT merge.
- At completion, report files changed, tests/checks, limitations, branch name, and manual verification commands.
- STOP and ask me to review, then commit and push manually.
